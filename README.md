# 🧩 Selfie Puzzle Game

A fun Python project that turns a webcam selfie into an interactive puzzle game!

The idea is simple: capture an image using your webcam, turn it into a scrambled puzzle, and solve it by arranging the pieces in the correct order. The project combines computer vision, hand gesture recognition, image processing, and game development to create a unique gaming experience.

## ✨ Features

-  Capture images using your webcam.
-  Use hand gestures to select and capture an area.
-  Detect hand movements using MediaPipe.
-  Split the captured image into a 3×3 puzzle.
-  Shuffle puzzle pieces automatically.
-  Solve the puzzle using drag-and-drop controls.
-  Use an image preview to help solve the puzzle.

## 🛠️ Technologies Used

- **Python** – Main programming language.
- **OpenCV** – Webcam access and image processing.
- **MediaPipe** – Hand tracking and gesture recognition.
- **NumPy** – Image and array operations.
- **Pygame** – Game interface and user interaction.

## 🎮 How to Play

1. Open the game and allow access to your webcam.
2. Use the pinch gesture to select the area you want to capture.
3. Capture the image to generate your puzzle.
4. The image will be divided into nine pieces and shuffled.
5. Drag and drop the pieces to arrange them in the correct order.
6. Use the preview, if available, to help complete the puzzle.

**Tip:** Keep your hand clearly visible to the webcam for better gesture detection.
